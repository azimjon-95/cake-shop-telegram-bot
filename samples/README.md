# Ovoz namunalari (aniqlikni baholash)

1. Telegram'dan sotuvchi ovozlarini `.ogg` qilib saqlang (Telegram Desktop → ovoz → "Save as").
2. Shu papkaga qo'ying va `cases.example.json` dan nusxa olib `cases.json` yozing (har fayl uchun kutilgan narxlar).
3. Serverda: `npm run voice:check -- samples/`

Hech narsa bazaga yozilmaydi. Qabul mezoni: `🚨 XATO AVTOMATIK: 0`.
Ovoz fayllari shaxsiy ma'lumot — gitga qo'shmang (`samples/*.ogg` .gitignore'da).
